# Prompt generic pentru un sprint

Lucrează în repository-ul local `geoint-flood-impact-dashboard`, pe branch-ul `feature/new-flood-impact-tool`.

Citește:
1. `codex_stabilization_sprints/00_RULES.md`
2. `codex_stabilization_sprints/<SPRINT_FILE>.md`

Implementează numai sprintul curent.
Nu trece la sprintul următor.
Rulează testele relevante.
Dacă sprintul afectează UI-ul, pornește aplicația și verifică lipsa erorilor la startup.
Afișează `git diff --stat` și `git status --short`.
Raportează fișierele modificate, testele și problemele rămase.
Oprește-te înainte de commit și push.
