# Screenshot Guide

Rezolutie recomandata: 1440 x 900 sau mai mare. Foloseste modul intunecat al
aplicatiei si evita afisarea terminalului, a caii `.env` sau a credentialelor.

## Capturi obligatorii

1. Ecran initial cu titlul, statusul GEE, judetul Galati si harta Romaniei.
2. Galeria Sentinel-1 cu scenele BEFORE si AFTER selectate.
3. Comparatorul vertical BEFORE/AFTER activ in aceeasi harta.
4. Rezultatul SAR cu `extindere preliminara` si bufferul activ.
5. Dynamic World cu datele efective si diferentele observate.
6. Elementele OSM, sursa cache/live si tabelul de prioritati.
7. Raportul PDF deschis la coperta si la harta sintetica.
