# Sprint 6 — UI OSM și mod prezentare

## Obiectiv
Înlocuiește afișarea tehnică cu una potrivită pentru comisie.

## Modificări
- Filtre: clădiri, drumuri, căi ferate, poduri, obiective critice, clădiri de referință.
- Adaugă `Mod prezentare`.
- Tabel prioritar: nume, categorie, status, distanță, `Zoom`.
- Indicator completitudine OSM.
- Niveluri infrastructură: esențial, important, context tehnic.
- `power=*` rămâne în cache; afișează implicit doar elementele relevante.
- Mod QA ascuns: counts, duplicate, relations omise, cache, timpi.

## Teste
Filtre, mod prezentare, tabel Zoom, completitudine, QA.
