# DEMO_GUIDE

Demo recomandat: 5-7 minute.

1. Porneste aplicatia cu `streamlit run app.py`.
2. Selecteaza presetul `Galati - September 2024 Floods`.
3. Ruleaza `Run SAR Flood Analysis`.
4. Arata sliderul before/after SAR.
5. Arata layerul `detected flood extent`.
6. Arata apa permanenta eliminata.
7. Arata terenurile intersectate de extinderea preliminara detectata.
8. Arata statisticile si raportul generat.
9. Explica limitarile metodologice.

Formulare recomandata: rezultatele reprezinta produse GEOINT preliminare de suport
decizional, nu confirmari oficiale in teren.
