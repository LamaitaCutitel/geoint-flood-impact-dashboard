# Prompt scurt pentru Codex

Lucrează în repository-ul local `geoint-flood-impact-dashboard`,
pe branch-ul `feature/new-flood-impact-tool`.

Citește:
1. `codex_sprints_ux_osm/00_RULES.md`
2. `codex_sprints_ux_osm/<SPRINT_FILE>.md`

Implementează numai sprintul curent.
Nu trece la sprintul următor.
Rulează testele cerute în sprint.
Dacă sprintul cere prewarm OSM, rulează obligatoriu scriptul și salvează logul.
Afișează `git diff --stat` și `git status --short`.
Scrie rezumat în `.codex-sprint-logs/<numar>-summary.md`.
Oprește-te înainte de commit și push.
