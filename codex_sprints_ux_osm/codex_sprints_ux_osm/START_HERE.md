# Start

1. Copiază folderul `codex_sprints_ux_osm` în rădăcina repository-ului.
2. Deschide terminalul în repository.
3. Rulează Codex CLI.
4. Pentru fiecare sprint, copiază promptul din `RUN_ONE_SPRINT_PROMPT.md`.
5. Înlocuiește `<SPRINT_FILE>` cu numele fișierului curent.

Exemplu pentru primul sprint:

```text
Citește:
1. codex_sprints_ux_osm/00_RULES.md
2. codex_sprints_ux_osm/01_RESTORE_SENTINEL_EXPLORER.md

Implementează numai sprintul curent.
Rulează testele relevante.
Oprește-te înainte de commit și push.
```
