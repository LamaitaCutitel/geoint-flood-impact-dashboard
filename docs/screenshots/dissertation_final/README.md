# Capturi finale pentru disertație

Capturile reale nu au fost generate automat deoarece mediul disponibil nu poate deschide browserul aplicației și nu poate executa fluxul GEE complet cap-coadă.

Pentru fiecare imagine solicitată există un fișier `.txt` cu pașii manuali. După validarea fluxului Galați, înlocuiește fiecare placeholder cu imaginea `.png` corespunzătoare.

## Reguli

- rezoluție minimă: `1440 × 900`;
- nu include terminalul;
- nu include `.env`, token-uri, chei sau credentiale;
- verifică statusul GEE înainte de captură;
- folosește formulări prudente în legende;
- nu prezenta rezultatele automate drept confirmări oficiale din teren.
